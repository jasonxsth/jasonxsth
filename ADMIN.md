# RENDART CMS

Редактор контента доступен по адресу `/admin/`. Он управляет общей конфигурацией, текстами десяти страниц и девятью кейсами, включая SEO-заголовки и описания. В основной подборке портфолио показываются восемь проектов; кейс кофейни используется в тематических подборках главной и B2B-страницы.

## Как публиковать

1. Создать fine-grained GitHub personal access token только для репозитория `jasonxsth/jasonxsth`
2. Разрешить ему `Contents: Read and write`
3. Открыть `/admin/`, вставить token и нажать `Подключить GitHub`
4. Изменить тексты и нажать `Опубликовать изменения`
5. Редактор обновит `content/site.json` в ветке `master`; GitHub Actions соберёт и опубликует сайт

Token не попадает в репозиторий и по умолчанию хранится только в памяти вкладки. Опция `Хранить до закрытия вкладки` использует `sessionStorage`; после работы доступ лучше отключить кнопкой в редакторе.

## Правила контента

- Короткие заголовки и интерфейсные подписи оформляются без завершающей точки; в полноценных абзацах сохраняется обычная пунктуация
- В списках одна строка соответствует одному элементу; разделитель `|||` отделяет заголовок от пояснения
- Цены, награды, статистику, клиентские результаты и обещания нельзя публиковать без подтверждения. Пока актуальный прайс не передан, ценовой блок использует формулировку «Индивидуальный расчёт»
- Структурные пути страниц и изображения меняются только в репозитории, не через интерфейс

## Ограничения первой версии

- Редактор управляет текстами и общими контактами, но не загружает изображения и видео
- Сохранение публикует изменения в GitHub Pages; приватный Sites-превью обновляется отдельным деплоем
- Если GitHub вернул конфликт, нужно переподключить доступ, повторить правки и сохранить актуальную версию
